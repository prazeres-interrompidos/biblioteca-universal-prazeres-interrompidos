# Biblioteca Universal — Prazeres Interrompidos

Primeira versão experimental da página "Livros Grátis", preparada para GitHub Pages.

## Ficheiros
- `index.html` — página completa (HTML, CSS e JavaScript)
- `biblioteca-universal.jpg` — fundo monumental da Biblioteca Universal

## Publicação no GitHub
1. Criar um repositório no GitHub.
2. Colocar estes dois ficheiros na raiz.
3. Ir a Settings → Pages.
4. Em "Build and deployment", escolher "Deploy from a branch".
5. Selecionar a branch `main` e a pasta `/ (root)`.
6. Guardar.

A página foi concebida para funcionar em computador, tablet e telemóvel.
